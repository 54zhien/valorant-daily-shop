UI 大改 · 入荷板（Liquid Glass）

把「四张卡」从电商列表里救出来，做成一块值班板：时间不再是旁边一个数字，而是板顶上一条会烧过去的引信； 品质不再是一行小字，而是书脊、斜带和一颗钻。 材质是 Liquid Glass —— 玻璃铺在控制层和内容层，靠透明度的层次和 20pt 以上的间距区分层级。 所有开发工具搬进「维护台」，首页只留看商店这一件事。

下面 7 个界面都是真的：点卡片可以翻开，倒计时在走。

玻璃只有一条配方：渐变填充 + 22px 模糊 + 内侧 1px 顶光；圆角三档 22 / 16 / 12。
间距：块间 12 / 页边 16 / 玻璃之间 ≥ 20（Apple 的硬建议，太近会有光学干扰）。 字压在玻璃上时，底部垫一层压暗渐层保证可读性。

Motion · 动效

  • 翻开：绕 Y 轴 180°，spring 0.55 / 0.8，四张错开 130ms
  • 品质点亮：斜带宽度 0 → 100%，180ms，跟在翻到 90° 之后
  • 引信：每秒推进，linear；数字用等宽滚动过渡
  • 降级：开了「减弱动态效果」→ 翻牌改成 120ms 交叉淡入

What changed · 留下了什么

  • 首页常驻日志面板 → 维护台
  • 首页三颗开发按钮 → 维护台
  • 「已连接」玻璃胶囊 → 票据弹药条（7 格 = ct 的 7 天）
  • 独立倒计时玻璃块 → 并入板顶，变成引信条
  • 卡片：玻璃保留，版面从"缩略图 + 元信息"改成满幅画 + 底部压字
  • 背景：MeshGradient 保留，光斑挪到边角，卡片区留干净
  • 字体三腔（机器腔 / 数据腔 / 人话腔）与无障碍标签
